# Vector API contract
All JSON endpoints under /api; cookie session authentication. Error JSON {detail: string}. IDs numbers. Date strings ISO YYYY-MM-DD; datetimes ISO UTC. Tracks 'forge' | 'apex'. Roles 'admin' | 'box_owner' | 'athlete'. Box types 'official' | 'standard'.

GET /api/bootstrap public -> {demo: bool, user: User|null, tracks:[{id,name,description}], boxes:[Box]}. User {id,name,email,role,box_id,box_name,box_type}; Box {id,name,city,type,athletes:number}.
POST /api/auth/login {email,password} -> User; POST /api/auth/logout -> {ok:true}; POST /api/auth/register {name,email,password,box_id:number|null} -> User (athlete only).
GET /api/dashboard -> {stats:[{label,value,detail}], activity:[{id,kind,title,detail,date}], weekly_activity:[{day,forge,apex}], challenge:Challenge|null, my_submissions:[Submission], box:Box|null}.
GET /api/workouts?track=&scope= -> Workout[] visible vector or user's box (admin all).
Workout {id,title,track,scope:'vector'|'box',box_id,box_name,scheduled_date,format:'for_time'|'amrap'|'emom'|'strength',duration_minutes,level:'all'|'scaled'|'rx',notes,exercises:[{movement,reps,load_kg}],author_name}.
POST /api/workouts same fields except id/box_name/author_name; admin scope vector, box_owner scope box, author and box set by server. Optional box_id for admin box workout. Supported movements squat,burpee,deadlift,thruster,wall_ball,row,run,ski,box_jump,push_up,pull_up,lunge,farmer_carry,sled_push. POST /api/workouts/{id}/complete {track?} -> {ok:true}; completion creates real activity (athlete only).
GET /api/challenges -> Challenge[]; Challenge {id,title,track,movement:'squat',target_reps,opens_at,closes_at,description,box_count,submission_count,enrolled:boolean,status:'upcoming'|'open'|'closed'}.
POST /api/challenges {title,track,movement:'squat',target_reps,opens_at,closes_at,description} admin only; POST /api/challenges/{id}/enroll {} box_owner only; enforces open/upcoming challenge.
GET /api/challenges/{id}/leaderboard -> {athletes:[{rank,athlete_name,box_name,box_type,time_seconds,reps,submission_id}],boxes:[{rank,box_name,box_type,athletes,best_seconds}]} approved only, sorted ascending time.
POST /api/challenges/{id}/submissions multipart fields video:file, consent:'true'; athlete only. -> Submission {id,challenge_id,challenge_title,athlete_name,box_name,status:'queued'|'processing'|'review'|'approved'|'rejected'|'failed',reps,time_seconds,confidence,analysis_note,video_url,created_at}; async analysis.
GET /api/submissions -> own athlete submissions / own box submissions / all for admin. GET /api/submissions/{id} -> Submission. POST /api/submissions/{id}/review {decision:'approved'|'rejected',reps:number,time_seconds:number,reason:string} admin only. GET /api/submissions/{id}/video -> protected video bytes.
GET /api/events -> Event[]; Event {id,title,track:'forge'|'apex'|'both',city,date,brand:'vector'|'independent',box_id,box_name,description,registration_count,registered}; POST /api/events {title,track,city,date,brand,description} admin or box_owner; box_id derives from owner, standard box cannot brand vector. POST /api/events/{id}/register {} athlete only.
GET /api/equipment -> Equipment[] {id,name,category:'forge'|'apex'|'both',stock,price_per_day,image_key,description}; GET /api/rentals -> Rental[] {id,event_id,event_title,box_name,start_date,end_date,status:'pending'|'confirmed'|'declined',total,notes,items:[{equipment_id,name,quantity,price_per_day}]}; POST /api/rentals {event_id,start_date,end_date,notes,items:[{equipment_id,quantity}]} box_owner (admin can use event box); POST /api/rentals/{id}/status {status:'confirmed'|'declined'} admin. Validate stock/date overlap upon confirmation.
GET /api/boxes -> Box[] public; POST /api/boxes {name,city,type,owner_name,owner_email,owner_password} admin creates box and its owner. PATCH /api/boxes/{id} {type:'official'|'standard'} admin. GET /api/admin/overview -> {users:number,boxes:number,official_boxes:number,pending_rentals:number,pending_reviews:number,ai:{available:boolean,detail:string},users_list:User[]}.
GET /api/health -> {status:'ok',database:'ok',ai:{available:boolean,detail:string}}.

Demo setup creates admin@vector.local, forge@vector.local (official box), norte@vector.local (standard box), atleta@vector.local (official box athlete), libre@vector.local (unaffiliated athlete); password VectorDemo2026! only in explicitly initialized demo database. Bootstrap demo flag permits showing these login shortcuts. No arbitrary client role switching: each uses real login. Demo seed fixtures include workouts/challenge/events/equipment, WITHOUT invented approved AI submissions or rankings. Empty ranking UI must show submit CTA.
